## What Actually Generated the Website?

The website was generated by one Qwen request from `askWorkspaceAgent()`.

The Website Designer Engine and Coding Engine are currently prompt rules inside that request, not independent runtime modules.

## What Actually Extracted Files?

`parseAgentJson()` and `normalizeWorkspaceFileActions()` extracted and normalized generated files.

## What Actually Saved Files?

The Workspace stream route loop called `writeProjectFile()` for each returned file.

## What Actually Verified Preview?

`verifyStaticPreview()` validated the HTML entry and linked assets.

## Current Pipeline Classification

Current Workspace pipeline is:

`Workspace stream orchestration + memory + one Qwen call + file normalization + static preview validation`

It is not yet:

`Full Codex-style multi-role orchestration`

## Shortest Enablement Path

1. Move CLI/extension Codex Intelligence Engine into a shared server-safe package.
2. Import it in `app/api/workspaces/[id]/agent/stream/route.ts`.
3. Execute deterministic stages before Qwen:
   - intent detection
   - classifier
   - planner
   - role pipeline
   - confidence engine
   - tool intelligence
4. Execute validation stages after Qwen:
   - reviewer
   - tester
   - debugger/autofix on failed preview
   - security reviewer
   - performance reviewer
   - finalizer
5. Persist learning outputs only after validation:
   - safe summaries
   - failure pattern
   - successful fix
   - suggested rule
6. Emit an event for every stage so future audits can prove runtime execution.
