# MIL Memory

MIL stores long-term project intelligence in extension storage, never in source files by default.

Stored memory:

- project summary
- architecture summary
- recent edits
- known issues
- successful fixes
- coding style
- frequent commands
- common errors
- predictions
- self-improvement notes

Secrets are excluded and never intentionally stored.

After each successful task, MIL records what worked, preferred commands, style signals, and future predictions so later tasks start faster.
